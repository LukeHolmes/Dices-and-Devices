Dice & Devises
A browser‑native roguelike dice deck‑builder built entirely from a single HTML file.

✨ Overview
Dice & Devises is a fast, neon‑styled dice roguelike that mixes strategic dice‑rolling, deck‑building elements, and branching progression. The entire game runs from one HTML file, powered by React, Tailwind CSS, in‑browser JSX transformation, and the Web Audio API for fully procedural sound effects.
Players roll, keep, swap, and manipulate custom dice to beat escalating score targets, collect powerful artefacts (“Devises”), and face bosses with unique rule‑twists. The game features a complete roguelike loop with shops, path choices, score mastery, corruption mechanics, and an Ascension mode for endless replayability.

🧩 Features

Single‑file deployment — easy to host, share, and embed
Roguelike progression — branching paths, shops, risk, bosses, final boss, ascension
Dice bag & discard system — swap dice from a bag, reshuffle when empty
Yahtzee‑style scoring — Chips × Multiplier, with mastery and combo bonuses
40+ items & consumables — passive synergies, one‑shot powers, and legendary artefacts
Boss fights — unique rules: target increases, gold drain, hidden dice, cursed values
Procedural audio — no files required; sound is generated by Web Audio API
Polished UI — CRT shader effects, glitch text, screen shake, animations, score visualiser
Fast Mode — skip animations for rapid playtesting


🕹 Gameplay Overview

Roll your dice and choose which ones to keep.
Use Swap to discard & redraw dice from your bag (costs 1 reroll).
Use Tilt to nudge values at increasing risk of a system failure.
Score into categories (Ones–Sixes, Full House, Straights, Yahtzee, Chance).
Bonuses include Efficiency, Flow (combo), Mastery (level‑up categories), and item triggers.
Between rounds, visit the Shop, take Loans, Gamble gold, pick your next Path, and face Bosses.
Defeat the final boss (The Source) to unlock Ascension mode.


🧠 Dice, Items, and Systems
Dice Types

d4, d6, d8
Weighted dice
Gilded dice (+gold on roll)
Status effects: Frozen, Burning, Radioactive

Items (Devises)
Passive artefacts that modify scoring, dice behaviour, gold generation, multipliers, synergies, and more.
Consumables
One‑use effects such as setting all dice to 6, reroll boosts, extra hands, randomising dice types, or manipulating gold.
Cyberdeck
Fill RAM through scoring to run “Programs” such as mining gold, adding hands, or rerolling specific dice.
