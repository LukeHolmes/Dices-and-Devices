# No-scroll layout (30 Oct 2026)

**Branch:** `cursor/no-scroll-layout-f4c3` (based on `cursor/playtest4-fixes-f4c3` while PR #53 is open)

## Goal

The game must never scroll at the document level and must not clip primary UI on common viewports. Long content scrolls only inside designated panels (`gb-panel-scroll`, `gb-modal-body`).

## Implementation

| Layer | Change |
|--------|--------|
| Document | `html, body` fixed; `#root-gutterbones` `position: fixed; inset: 0; height: 100dvh; overflow: hidden` |
| Shell | `gb-app-shell` grid; each phase uses `gb-screen` (flex column, `min-height: 0`) |
| Scale | CSS vars `--gb-die`, `--gb-pad`, `--gb-title` via `clamp()` / `vmin`; container queries trim HUD on short heights |
| PLAY mobile | Three-tab dock: **ALLEY / PAYOUTS / STASH** (replaces page scroll + full-width stash opener) |
| Modals | `gb-modal-fit` + `gb-modal-body` for Help, Case Files, Safehouse, Gamble, Rap sheet, Victory |
| QA hook | `?layoutAudit=1` exposes `window.__GB_LAYOUT_AUDIT__` for Playwright |

## Automated audit

```bash
npm install          # once — installs playwright
npx playwright install chromium
npm run test:layout  # 84 cases: 12 screens × 7 viewports
npm run check        # unit tests + layout + known-issues
```

Assertions per case:

- `document.scrollHeight <= innerHeight` (and width)
- Each visible `[data-layout-key]` within the viewport (hidden panels skipped)

Screens: lineup, PLAY, shop, carving, gamble, rap sheet, safehouse, help dossier, system menu, case files, first-run overlay, mechanic toast.

Viewports: 1280×800, 1366×768, 1440×900, 1920×1080, 1024×768, 844×390, 390×844.

Screenshots: `/opt/cursor/artifacts/no-scroll-layout/{scenario}-{viewport}.png` (generated by `test:layout`).
